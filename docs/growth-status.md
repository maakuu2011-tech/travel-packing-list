# 成長データの定点記録

週次または月次の**取得できた確定値だけ**を追記する。日次詳細ログは Git 管理外のままにし、日々の数値だけで commit を作らない。原則として週次の改善・判断に合わせて更新し、値が取得できない項目は「計測不可」と明記する。集計期間、取得日、取得元、検索タイプ、比較対象期間を必ず残す。期間が重なる比較や、季節の違う28日比較から成長を断定しない。

## 初回の計測待ち（2026-10-15）

- Search Console: 計測不可（このリポジトリに実測の保存なし。接続済み画面で確認後に記録）
- Cloudflare Web Analytics: 計測不可（このリポジトリに実測の保存なし。接続済み画面で確認後に記録）
- ガイド→チェックリスト遷移、生成、保存、印刷、共有: 計測不可（成果イベント設定を確認できていない）
- 伸びている／伸びていないテーマ、新規需要: 判定保留。初回の比較可能な実測取得後に記録する。
